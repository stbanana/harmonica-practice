# 口琴练习器（三角洲键位）

部署在 GitHub Pages 上的纯前端口琴练习器。键位与《三角洲行动》游戏内口琴完全一致，
练完直接进游戏就能吹。无构建、无依赖：原生 HTML + CSS + ES modules。

在线使用：`https://stbanana.github.io/harmonica-practice/`

## 键位规则（与游戏一致）

| 按键 | 作用 |
| --- | --- |
| `Z X C V B N M` | do re mi fa sol la si（中音） |
| `，`（逗号） | 高音 do |
| **按住左键** | 整排降到低八度 |
| **按住右键** | 整排升到高八度 |
| 右键 + 逗号 | 高高音 do（再按中键 = 高高音 #do） |
| **按住中键** | 升半音（每个白键 + 中键 = #音） |

- 单音演奏：多个键按下时后按的优先；松开修饰键时正在按住的音会“切音”重触发（与游戏一致）。
- 等价指法算通过：例如高音 do 用「逗号」或「右键 + Z」都能吹出来，练习判定按**结果音高**匹配。
- 逗号键需要键盘布局上逗号是独立按键（美式布局无需 Shift）。
- 请使用英文输入法状态按键。

## 三种模式

1. **自由练习** — 直接吹奏，实时显示当前音（音区 + 唱名 + 音名 + 按键组合）与音高条。
2. **瀑布流引导** — 导入 MIDI 或选择内置曲目，8 列瀑布流对应 8 个物理键：
   - **跟练**：下一音符自动停靠在判定线等待，按对才前进，无时间压力；
   - **节奏**：连续滚动 + 时机判定（±80ms PERFECT / ±300ms GOOD / 过线 MISS），
     统计准确率、连击、评分，曲终结算。
   - 音符颜色 = 音区（橙=低 / 绿=中 / 蓝=高 / 紫=高高），块内直接写明所需修饰键（左键/右键/中键，各自着色），
     右上角 ♯ 徽标 = 需要中键（短块上显示）；判定线上方有「下一音」文字行，
     底部按键行会预高亮下一音符要按的键和修饰灯。
   - 快捷键：`空格` 开始/暂停，`Esc` 关闭结算。
3. **简谱看谱** — 导入简谱**图片**（文件 / 拖拽 / Ctrl+V 粘贴截图），缩放平移看谱自练，
   底部实时反馈你吹出的音。图片 ≤2MB 会自动缓存到本地，下次打开还在。

## MIDI 导入说明

- 支持标准 MIDI 文件（format 0/1，含变速 tempo map；不支持 SMPTE 时序）。
- 默认自动选择音符最多的非鼓音轨，可在「音轨」下拉中手动选择或「合并全部音轨」。
- 和弦会被归并成最高音（口琴是单音乐器）；若旋律在低声部，请用音轨选择器换轨。
- 音域超出可演奏范围（低音do ~ 高高音#do）时整体八度移位适配；仍超出的音符灰色显示、免判定。
- 修改「中音 do」基准八度会按新基准重建曲目并重置当前会话。

## 本地运行与测试

```bash
# 静态服务器（ES modules 不能直接 file:// 打开）
python -m http.server 8000
# 打开 http://localhost:8000

# 单元测试（需 Node 18+；仅测试用，无构建依赖）
node --test tests/
```

## 部署到 GitHub Pages

1. 把仓库推送到 GitHub；
2. 仓库 `Settings → Pages → Source` 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存；
3. 稍等片刻即可通过 `https://<用户名>.github.io/harmonica-practice/` 访问。

## 说明与边界

- 音源是 WebAudio 合成的简易口琴音色（三角波 + 泛音 + 轻微颤音），仅作音高反馈用。
- 主题支持 **自动（跟随系统）/ 深色 / 浅色** 三种，右上角「主题」按钮循环切换。
- 按钮类控件（下拉、播放键等）不触发修饰键；画布、自由练习区与简谱图片区都是修饰键区域——按住音符时用左键拖动图片会瞬时变音，左键本就是降八度修饰键，与游戏行为一致。
- 速度 0.5×~1.5× 缩放歌曲时间，判定窗随歌曲时间同步缩放（慢速练习更宽容）。
